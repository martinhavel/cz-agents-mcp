IČO lookup, EU+OFAC sanctions, ISIR insolvency, unreliable VAT payer, statutory body,

**Long description:**
For KYC/AML, supplier onboarding and counterparty checks. The skill tells the agent
when to use which cz-agents tool (dd, ares, isir, sanctions, adis, eu-registry), keeps
calls low for free-tier limits, stops on `tier_required` and shows the upgrade link,
separates sanctions name matches from confirmed hits, treats unavailable sources as
"not verified", respects GDPR data minimisation and writes a compliance-ready report.
Works fully on the free tier; paid DD+ tools are optional.
